A language model, built from the first byte.

CogNova 3.0 is an effort to build a Bangla, English and code language model from scratch: our own tokenizer, our own transformer and our own training loop. Every step is small, measured and written down before the next one starts.

Why build from scratch

Understand every layer before scaling any of it.

Most Bangla AI products wrap a model someone else trained. CogNova goes the long way round, so the team knows exactly what the model sees, how it learns and where it breaks.

Bangla first

The tokenizer and the data plan treat Bangla as a first-class language next to English and source code, not an afterthought.

Small, honest steps

Each milestone has a written protocol, expected results and limits, and is compared against what actually happened.

Runs on modest hardware

Everything so far trains and tests on a single 6 GB laptop GPU, with resource gates before anything larger.

The pipeline

Five gates, each with its own evidence.

Nothing moves forward on a hunch. A gate closes only when its tests pass and its report is written.

D1 · Data and tokenizer

Original synthetic fixtures and a dependency-free byte-level BPE tokenizer. 32 tests and 10,000 exact roundtrips.

C0 · Model correctness

A small decoder-only transformer checked shape by shape on CPU and GPU before a single optimizer step.

T0 · Bounded training

120 steps under a predeclared protocol. Finite loss, tiny-batch overfit and a written expected-vs-actual report.

R2 · Recovery

A fresh process reloads a checkpoint and replays 60 steps. The result matches the original run exactly.

W1 · Real-text audit

200 Wikipedia articles, 100 Bangla and 100 English, audited for quality, duplication and length. 82 tests.

Model card

C0: the reference model.

C0 is deliberately tiny. Its job is not to be clever but to be provably correct, so that every later, larger model can be checked against it.

  • Decoder-only transformer in plain PyTorch
  • FP32 reference implementation, CPU and GPU
  • Deterministic runs and exact checkpoint replay
  • Weights and checkpoints kept local, out of Git

Principles

How the work is done.

Write it down first

Each run has a protocol before it starts and a results report after, in Bangla and English.

No overclaiming

Results state their limits. A passing test on synthetic data is reported as exactly that.

Private by default

Datasets, weights and checkpoints stay local and out of version control.

Spend only with approval

New downloads, cloud compute or longer training each need a separate sign-off.
