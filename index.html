CogNova Models: a Bangla-first model family, measured before it is trusted

Sifat AhmedSyncAura ResearchDhaka, BangladeshStarted 10 October 2026
Abstract

CogNova is SyncAura's research into language models for Bangla, English and code. The family now has four models on two tracks. CogNova 3.0 is built from the first byte: our own tokenizer, transformer and training loop, on one consumer graphics card. CogNova 8.0, 9.0 and Media 1.0 are built on open-weight bases with our own identity, answer rules and settings, and run entirely on the owner's computer inside SI Agent. Every model is held to the same method: the expected result is written down first, the run is bounded and repeated, and the actual result is recorded next to it, including when it falls short. Each model below has its own questions, method, experiments, figures, findings, limits and next steps.

Chapter 1 · CogNova 3.0

Building a Bangla-first language model from the first byte

Abstract

CogNova 3.0 asks whether a small team, on one consumer graphics card, can build a useful language model for Bangla, English and code without starting from someone else's weights. We write the tokenizer, the transformer and the training loop ourselves, and treat every step as an experiment. Six experiments are complete. A 1.33M-parameter reference model trains stably, overfits a tiny batch on purpose, and resumes from a checkpoint with zero numerical difference. Our audit of real Wikipedia text showed what the next model needs: context chunking, stronger cleaning and record-level rights clearance before any real training starts.

§1.1 Research questions

What we are trying to find out.

Many Bangla language tools today are fine-tuned from models trained mostly on English. CogNova starts from the other end.

RQ1

Can a tokenizer treat Bangla as a first-class script?

Many tokenizers split Bangla into far more tokens than English, which wastes context and compute. We build our own byte-level BPE and measure it on both languages.

RQ2

Can every part of the stack be verified, not just trusted?

Each component is checked against a reference on CPU and GPU before it is used, so later results can be traced to code that is known to be correct.

RQ3

How far does one 6 GB consumer GPU go?

All work runs on a single RTX 3050. We measure memory, time and stability for each step so scaling decisions rest on numbers, not hope.

RQ4

Can training data be clean, traceable and rights-checked?

Every text window keeps its source, revision, licence evidence and byte offsets. Nothing enters training until its rights are actually cleared.

§1.2 Method

Evidence-gated research.

No experiment moves the project forward on a feeling. Each one follows the same five steps, and the next gate opens only when this one has evidence.

01

Declare

Write the protocol, limits and pass thresholds before running anything.

02

Bound

Cap time, steps, tokens, downloads and memory so a run cannot drift.

03

Run

Execute once, on fixed seeds and fixed splits, with no tuning on held-out data.

04

Compare

Record expected versus actual in a table. Targets are never moved afterwards.

05

Preserve

Hash and keep evidence, so anyone can check exactly what happened.

A passed gate means the engineering works as declared. It is never read as proof of language ability. That needs representative benchmarks, which come later.

§1.5 Findings

What we learned.

The from-scratch stack is sound

Tokenizer, model and optimizer are verified, numerically stable on a 6 GB GPU, and reproducible to the last bit.

Synthetic data has done its job

It proved the pipeline learns. It cannot teach language, so held-out quality now depends entirely on real data.

Context, not compute, is the first wall

Almost no real article fits in 128 tokens. Windowing works today; a longer context and a tokenizer tuned for Bangla are the real fix.

Rights are the slowest gate

Licence evidence is recorded for every article, but page-history and imported-text exceptions still block training use. We will not skip this.

§1.6 Limits and open gates

What these results do not show.

Said plainly, so the 3.0 numbers above are not read as more than they are.

  • No benchmark of real Bangla, English or code ability has been run yet.
  • Held-out sets are tiny (3 texts in T0), so generalisation cannot be judged.
  • The 30-minute sustained GPU and memory test was paused at 5.5 minutes and is not passed.
  • No Wikipedia text is cleared for training; W1 and W2 are audit-only.
  • Windows have no overlap, so meaning across window edges is lost.
  • Trained weights stay private and local. No model is released.

Chapter 2 · CogNova 8.0

The quick one: an answer before the pause

Abstract

CogNova 8.0 is the fast model in SI Agent, made for short questions and spoken turns where the answer has to start at once. It is built on a small open-weight base with our own identity, language rules and settings, and installed from our own package on the owner's computer. In the last evaluation, three rounds per case, it passed every case of every group: it names itself correctly in Bangla, English and Hindi, answers in the script it was asked in, stays short and admits what it cannot know. What the suite does not measure is knowledge, and that is where 8.0 is weakest.

§2.1 Research questions

What 8.0 has to prove.

A quick model is only useful if being quick does not make it careless.

Q1

Can a small model hold its identity in three languages?

Asked "who are you" in Bangla, English and Hindi, it must give its own name, in Latin letters, in the language of the question.

Q2

Does the script of the question decide the answer?

An English question about Bangladesh must get an English answer. The subject must never pull the language.

Q3

Can it stay short without losing the answer?

A one-fact question gets one fact: under 250 characters, no preamble, no emoji.

Q4

Will it admit what it cannot know?

A drive it cannot see, tomorrow's weather, a file it was never given: it must say so plainly instead of guessing.

§2.2 Method

One suite, fixed sampling, every answer kept.

The same suite measures 8.0, 9.0 and Media 1.0, so their numbers can be compared directly.

01

Declare

Write the five test groups and what counts as a pass before any model answers.

02

Fix

Ask every model the same way: num_ctx 4096, temperature 0.2, seed 17, no system message.

03

Isolate

Unload the other models first, so each one is measured with the machine to itself.

04

Repeat

Three rounds per case. A pass means every round passed, not the best of three.

05

Keep

Every answer goes into results/ with its date, so any number can be checked later.

8.0 is tested with no system message, so what is measured is the model's own instructions. Inside SI Agent it keeps the settings in its Modelfile: temperature 0.6, top_p 0.9, top_k 40.

§2.5 Findings

What we learned.

Built for speed

Short questions, voice turns, anything that should answer at once. A spoken answer has to start before the person wonders whether the app heard them.

Clean on behaviour

Passed every case in the last run: says what it is in three languages, answers in the script it was asked in, stays short, admits what it cannot know.

Instructions steer the language

One named country in the opening line was enough to change the language of answers. No examples in the instructions, for the same reason.

Weak on facts

A small model states a wrong date or price with the same calm as a right one. Use 9.0 for anything that matters and check any number.

§2.6 Limits

What these results do not show.

Said plainly, so the 8.0 numbers are not read as more than they are.

  • The suite measures behaviour, not knowledge. A full score says nothing about facts.
  • Before a fix it answered "Bangladesh-এর রাজধানী দহল হয়": the language was fixed, the wrong word was the model.
  • Honesty is a heuristic: it looks for a phrase that admits not knowing.
  • Long Bangla, nuance, multi-step reasoning and code beyond a few lines are weaker.
  • Three rounds at fixed sampling show consistency, not the full range of answers.
  • The weights stay on the owner's computer. No model is released.

Chapter 3 · CogNova 9.0

The careful one: better Bangla for work that matters

Abstract

CogNova 9.0 is the everyday chat model in SI Agent, for longer answers and work where being right matters more than being instant. It sits on a larger open-weight base than 8.0, with the same identity and answer rules, and step-by-step reasoning switched off so that it answers instead of thinking out loud. In the last evaluation it passed every case of language, brevity and honesty, and its Bangla is clearly better than 8.0's. One fault stays open: asked in Bangla, it writes its own name in Bangla letters.

12/12answers in the right script
9/9honesty: admits what it cannot know
6/9identity, one open fault
13.2tokens per second
§3.1 Research questions

What 9.0 has to prove.

A careful model has to be worth its extra seconds.

Q1

Is the better Bangla worth four times the wait?

It writes at about a quarter of 8.0's speed. Its answers have to be visibly better to justify that.

Q2

Can it answer directly instead of thinking out loud?

With reasoning on, one line took about 130 seconds. A chat model has to answer in seconds.

Q3

Does it fit a 6 GB graphics card?

It wants about 8 GB. Part of it has to sit in system memory and still answer in a few seconds.

Q4

Can a prompt fix its Bangla self-name?

It writes "কগনোভা ৯.০". Four different prompt fixes were measured to find one that removes it without harm.

One suite, fixed sampling, every answer kept.

The same suite as 8.0 and Media 1.0, so the three can be compared directly.

§3.5 Findings

What we learned.

Better language, slower answers

Its Bangla and its explanations are clearly better than 8.0's. It writes about four times slower, but still answers in a few seconds on a 6 GB graphics card.

Reasoning off made it usable

From about 130 seconds a line to a few seconds. For a problem that needs real steps, ask for the steps explicitly.

Some habits belong to the base

Writing proper nouns in Bangla letters survived four measured prompt fixes. Some faults cannot be prompted away without harming the answers.

Cosmetic where it shows

Inside SI Agent the app sends its own identity, so a person chatting does not see the Bangla self-name.

§3.6 Limits

What these results do not show.

Said plainly, so the 9.0 numbers are not read as more than they are.

  • The suite measures behaviour, not knowledge. Better answers are judged by reading them, not yet by a benchmark.
  • With reasoning off it is not a reasoning model.
  • The Bangla self-name fault is open after four measured fixes.
  • On a 6 GB card part of it runs from system memory, so it is slower than its size suggests.
  • Honesty is a heuristic: it looks for a phrase that admits not knowing.
  • The weights stay on the owner's computer. No model is released.

Chapter 4 · CogNova Media 1.0

The one that reads pictures: copy, never guess

Abstract

CogNova Media 1.0 does one job in SI Agent: it looks at a picture the person attached and reports what is in it, including any text, before a chat model answers. It is built on a small open-weight vision base with our own instructions, and it runs at temperature 0, because a model that copies text must not get creative. Its instructions matter more than the others', because SI Agent reads a picture with no instructions of its own. In the last evaluation every round returned all eight known strings from the test receipt, in Bangla and English, and invented no number.

8/8known strings read from the receipt
6/6picture rounds passed
0numbers invented
68.6tokens per second
§4.1 Research questions

What Media 1.0 has to prove.

Reading a picture is only useful if what comes back can be trusted.

Q1

Can it copy text exactly, in its own script?

Bangla stays Bangla and English stays English, letter for letter, including prices and place names.

Q2

Will it say "unclear" instead of guessing?

A blurred digit must be reported as unclear. A wrong price that looks right is the worst outcome.

Q3

Does it stay in its lane?

It reports what is in the picture and never answers the question in the chat model's place.

Q4

Does the question's language change what it reads?

Asked in Bangla or in English, it must read the same eight strings.

§4.6 Limits

What these results do not show.

Said plainly, so the Media 1.0 numbers are not read as more than they are.

  • The test picture is clean, rendered text: the easy case.
  • Handwriting, low light, angled photos, dense tables and faint scans are untested.
  • Bangla letters are where it slips first.
  • Do not trust it for a number that matters (a price, an account, a dose) without looking yourself.
  • Its identity answer in Bangla is still in English.
  • The weights stay on the owner's computer. No model is released.
