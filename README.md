# CogNova Models website

The official showcase website for **CogNova Models**, live at https://cognova.sifat.codes

CogNova is SyncAura's AI research into Bangla-first language models. The site presents the whole family as a research report, one chapter per model: CogNova 3.0 (trained from the first byte), CogNova 8.0, CogNova 9.0 and CogNova Media 1.0.

A static site (plain HTML, CSS and JavaScript, no build step). `index.html` is the page, `base.css` and `base.js` hold the shared styles and scripts, and `img/` holds screenshots.

Built by Sifat Ahmed.
